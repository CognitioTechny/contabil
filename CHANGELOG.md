# Changelog

## 1.0.0 - 2026-10-23

### Added

- Phase 5 distribution: GitHub Actions (coding standard; PHPUnit on PHP 8.2, 8.3 and 8.4 with SQLite and with MySQL; the independence job that installs the package in an empty CodeIgniter 4 application, creates a chart, posts, reverses, closes a period, reads the ledger and trial balance, and posts with 50 concurrent processes checking the numbering stays gap-free), the CodeIgniter coding standard (`composer cs`), a contract test between `docs/openapi.yaml` and the registered routes, and the guides `installation`, `entries`, `reports`, `events`, `posting-rules`, `integration-guide`, `migration-guide`, `faq` and `versioning`, plus `CONTRIBUTING.md`.
- Phase 4 books and statements: General Ledger (one account, group roll-up, cursor pagination, running balance in the account's nature; code ranges), Journal, Trial Balance (with cache divergence check), Income Statement (cash or accrual basis, proportional recognition through settlements with the residual on the last one), Balance Sheet (accrual, with the unclosed result), Statement by source, JSON / CSV / PDF output (PDF through `PdfRendererInterface`, the `contabilPdfRenderer` service), and the `/reports/*` API with `contabil.reports.view` and `contabil.reports.export`.
- Phase 3 entry engine: `Money`, `JournalEntry` with drafts, posting, reversal and the SHA-256 hash chain per entity; gap-free numbering per entity and fiscal year safe under concurrency; idempotency keys; atomic batches; settlements; period closing and reopening; fiscal year closing with a result-closing entry, reversible while the next year is open; the balance cache with `contabil:recalculate-balances`; `contabil:verify-integrity`; the PSR-14 events `EntryPosted`, `EntryReversed`, `EntrySettled`, `PeriodClosed`, `PeriodReopened`, `FiscalYearClosed` and `FiscalYearReopened`; optional posting rules; the `/entries`, `/periods` and `/fiscal-years/{id}/close|reopen` API; the `resultAccountCode` setting; `acc_entries.chain_position`.
- Phase 2 chart of accounts and fiscal calendar: account invariants (unique codes with an optional per-level mask, leaf and group, nature from type with contra accounts, inherited type, cycle-free moves, movement protection), fiscal years that generate 12 gap-free monthly periods, the use cases `CreateAccount`, `UpdateAccount`, `MoveAccount`, `DeactivateAccount`, `ReactivateAccount`, `DeleteAccount`, `GetAccountTree`, `ImportChart` (all or nothing, per-row errors), `ExportChart`, `CreateFiscalYear`, `ListPeriods` and `CreateEntity`, the optional `generic` and `professional-services` seeds, `contabil:seed-chart` and `contabil:create-entity`, the `/accounts` and `/fiscal-years` API with `docs/openapi.yaml`, the `accountCodeMask` setting, and the `contabil*` services through which hosts register their port adapters.
- Phase 1 package core: Composer skeleton, ports with default implementations and reusable contract tests, configuration, versioned schema migrations, `contabil:install`, `contabil:migrate` and `contabil:status`, the domain exception hierarchy with its HTTP mapping, and the architecture test.
